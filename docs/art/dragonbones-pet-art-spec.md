# 桌宠 2D 动物形象 — 美术 / 绑定规格表(交给画师 / 自己照做)

> 用途:为「桌面宠物(Electron 桌宠)」制作一只**可骨骼绑定**的 2D 动物 Q 版形象。
> 绑定引擎:**DragonBones**(2D 骨骼;与 Live2D 同类的"分层 PSD"工作流)。
> 这份文档定义**画师要交付什么**,以及**为绑定/做动画需要满足的硬性要求**。

---

## 0. 一句话需求(可直接发给画师)

> 正面朝向的 **Q 版 / 3 头身 [动物种类，如猫/狐狸/小熊]** 形象,**分层拆件交付一个 PSD**:每个会动的部位(头、耳、眼白、瞳孔、眉、嘴、身体、四肢、尾巴等)各自独立图层、透明背景,**关节重叠处与被遮挡的部分都要补画完整**,用于 2D 骨骼绑定(DragonBones / Live2D 同类格式)。

---

## 1. 交付格式

- **文件**:一个**分层 PSD**(`.psd`)。每个可动部位 = 一个独立图层(或图层组)。
- **背景**:全透明(无背景图层)。
- **画布尺寸**:建议 **1024–2048 px 高**(角色实际占画面高度 ≥ 1000px)。分辨率高,网格形变才平滑。
- **色彩**:RGB,sRGB。
- **不要**:不要合并图层、不要把多个部位画在同一层、不要只给一张扁平成品图(那种没法绑骨,只能逐帧)。

---

## 2. 拆件清单(图层结构)

按"会不会单独动"来拆。**命名用下面的英文名**(绑定时代码按这些名字找骨骼/槽位,省去返工)。左右用 `_l` / `_r`。

| 图层名 | 部位 | 说明 |
|---|---|---|
| `tail` | 尾巴 | 在身体后面,可加摆动物理 |
| `ear_l` / `ear_r` | 左右耳 | 可加轻微摆动 |
| `head` | 头(底) | 脸的底盘 |
| `brow_l` / `brow_r` | 左右眉 | 可选,做表情用 |
| `eye_white_l` / `eye_white_r` | 左右眼白 / 眼眶 | 固定在头上 |
| `pupil_l` / `pupil_r` | 左右瞳孔 | **必须和眼白分开**(光标跟随时眼珠要单独动) |
| `eyelid_l` / `eyelid_r` | 上眼皮(用于眨眼) | 或用"睁/半/闭"三张眼图替代(见 §4) |
| `mouth` | 嘴 | **另给 2–3 张不同嘴型**(见 §4) |
| `blush` | 腮红 | 可选,表情用 |
| `body` | 身体 | 躯干 |
| `arm_upper_l` / `arm_lower_l` | 左臂(上臂/前臂) | 想让手肘弯就拆上下两段;不弯可合成一段 `arm_l` |
| `arm_upper_r` / `arm_lower_r` | 右臂 | 同上 |
| `hand_l` / `hand_r` | 左右手 | 可选独立 |
| `leg_l` / `leg_r` | 左右腿/脚 | |
| `accessory_*` | 配件(围巾/铃铛等) | 各自独立 |

> 拆多细取决于想要多灵活。**最小集**:头、左右耳、眼白、左右瞳孔、嘴、身体、左右臂、左右腿、尾巴。

---

## 3. 关节 / 遮挡硬性规则(最容易被忽略、最重要)

1. **被遮挡的部分要补画完整**:例如上臂要一直画到身体底下一截、脖子要画到头底下、大腿画进身体 —— 这样部位旋转/移动时**不会露出空缺或破绽**。
2. **关节处适当重叠**:相邻部位在关节处留一点重叠区,旋转时接缝不会裂开。
3. **姿势**:正面、自然站姿(手臂略微离开身体,方便绑骨);不要叉得太开,也不要紧贴身体。
4. **对称件分开**:左右耳/眼/臂/腿各自独立图层(不要左右画在一层)。
5. **瞳孔可在眼白范围内自由移动**(眼白要比瞳孔大一圈),用于看向光标。

---

## 4. 表情用的"替换件"(桌宠交互需要)

桌宠有**投喂**和**情绪**反应,这些在 DragonBones 里多用**"槽位换图"**实现 —— 所以请额外提供这些小图(同样独立图层):

- **嘴型** ≥ 3 张:`mouth_normal`(常态)、`mouth_open`(张嘴/吃)、`mouth_happy`(笑)。可再加 `mouth_sad`。
- **眼睛状态**:用于眨眼/表情 —— `eye_open`(常态)、`eye_half`、`eye_closed`;以及可选 `eye_happy`(笑眼 ^^)。
- **可选**:`brow_up`(惊讶)、`blush`(害羞/满足)。

> 对应桌宠的状态:**馋(渴望)= 张嘴 + 盯着看 + 可选口水/腮红**;**满足 = 笑眼 + 笑嘴 + 腮红**。画师只要把这些"零件图"给齐,绑定时由我来组合成状态。

---

## 5. 需要做的动画(motion 清单)

绑定后要做这些循环/触发动画。**动画命名用下面的英文名**:

| 动画名 | 用途 | 类型 | 优先级 |
|---|---|---|---|
| `idle` | 待机:轻微呼吸 + 偶尔眨眼/晃动 | 循环 | 低 |
| `greet` | 出场/打招呼 | 单次 | 中 |
| `react` | 被点击/被摸的反应 | 单次 | 高 |
| `happy` | 开心 | 单次 | 高 |
| `receive` | 被投喂"吃东西"的反应 | 单次 | 高 |

- **光标跟随不需要做动画** —— 头/眼骨骼由程序实时驱动(只要 §2 里 `head` 是独立骨、瞳孔独立)。
- **馋/满足"表情"** 主要靠 §4 的换件 +(可选)短动画,不强制单独做。
- `talk` / `think`(AI 说话/思考)是后续 AI 联动(Plan 4)用,**现在可不做**。

---

## 6. 绑定方说明(交付后我方负责,画师不用管)

- 在 DragonBones Pro / LoongBones 里:导入 PSD → 自动建槽位 → 建骨骼(root→body→head,四肢链)→ 关节处加**网格 FFD**做软形变 → 绑权重 → 做 §5 的动画。
- 头骨 `head`、瞳孔骨用于光标跟随(程序驱动)。
- 导出 `*_ske.json + *_tex.json + *_tex.png`,接进桌宠 App(技术侧已验证)。

---

## 7. 交付校验清单(画师自检)

- [ ] 一个分层 PSD,透明背景,角色高度 ≥ 1000px。
- [ ] §2 的部位都拆成了独立图层,命名按表(英文、左右 `_l/_r`)。
- [ ] 瞳孔与眼白分开;眼白比瞳孔大一圈。
- [ ] **所有被遮挡处都补画完整**(隐藏上层后看,下层没有空洞)。
- [ ] §4 的替换件(嘴型 ×3、眼态 ×3 等)都给齐、独立图层。
- [ ] 没有合并图层、没有只给扁平成品图。
